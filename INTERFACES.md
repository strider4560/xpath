# Internal coordination contract

Public exports at crate root: Error, ErrorKind, Result, Navigator, NodeKind, Axis, ExpandedName, Value, Context, Namespaces, NodeSetPool, FunctionContext, FunctionTable, Limits, XPath, and the module `ast`. All worker files may import these. No worker should edit root-owned files.

Parser owns `ast.rs`, `parser.rs`: `pub(crate) fn parse(source: &str) -> Result<Expr>`. AST definitions: `QName { prefix: Option<String>, local: String }`; `Expr::{String(String), Number(f64), Variable(QName), Function(QName, Vec<Expr>), Unary(Box<Expr>), Binary(BinaryOp, Box<Expr>, Box<Expr>), Path { base: Option<Box<Expr>>, absolute: bool, steps: Vec<Step> }, Filter { base: Box<Expr>, predicates: Vec<Expr> }`; `Step { axis: Axis, test: NodeTest, predicates: Vec<Expr> }`; `NodeTest::{Any, Name(QName), NamespaceWildcard(String), Node, Text, Comment, ProcessingInstruction(Option<String>)}`; `BinaryOp::{Or,And,Eq,Ne,Lt,Le,Gt,Ge,Add,Sub,Mul,Div,Mod,Union}`. Since 0.2.0 (R1) `ast` is a public module and the AST types and members are `pub` (read-only: `QName` and `Step` are `#[non_exhaustive]`, and only the parser builds an `XPath`); `XPath::ast(&self) -> &ast::Expr`. AST types derive Debug, Clone, PartialEq. Axis is in model.rs.

Functions worker owns `value.rs` and `functions.rs`. `Value<N>::{Nodes(Vec<N>), Boolean(bool), Number(f64), String(String)}`; methods `to_boolean(&self)->bool`, `to_number<T: Navigator<Node=N>>(&self, nav:&T)->Result<f64>`, `to_string<T: Navigator<Node=N>>(&self, nav:&T)->Result<String>`, `as_nodes(&self)->Result<&[N]>`. Conversion must use earliest document-order node even if external caller constructed unsorted set. Expose pub(crate) `string_to_number(&str)->f64`, `number_to_string(f64)->String`, `xpath_round(f64)->f64` as useful. Builtin dispatch `pub(crate) fn call<N:Navigator>(name:&str, args:&[Value<N::Node>], ctx:&FunctionContext<'_,N>, remaining:&mut usize)->Option<Result<Value<N::Node>>>`. None means unknown function; arity/type errors are Some(Err). Complete 27 core functions only. Core navigation shares the evaluator budget. `first_node` validates handles and returns a fallible result.

Root owns model/error/context/eval/lib. `FunctionContext<'a,N:Navigator> { pub navigator:&'a N, pub node:&'a N::Node, pub initial_node:&'a N::Node, pub position:usize, pub size:usize }`. `Context::new(nav:&N,node:N::Node)`; builder methods `with_namespace(prefix,uri)`, `with_variable(local_name,value)`, `with_variable_ns(ExpandedName,value)`, `with_function(ExpandedName, closure)`, `with_limits(Limits)` and `with_focus(position,size)->Result<Self>`. Function closures `Fn(&FunctionContext<'_,N>, &[Value<N::Node>]) -> Result<Value<N::Node>>` (no Send/Sync bound required). `XPath::compile(&str)->Result<XPath>`; `XPath::evaluate(&Context<N>)->Result<Value<N::Node>>`. `XPath::select(&Context<N>)->Result<Vec<N::Node>>` convenience. Root namespaces and variables are dynamically bound per evaluation.

Integration additions: `Navigator::validate_node` defaults to success, for adapters to reject stale/foreign handles before infallible kind/order operations. `Context::with_default_element_namespace` is an explicit embedding option, affecting only unprefixed element tests. The optional XML adapter rejects expanded element depth over 256 before invoking roxmltree's recursive tokenizer.

D21 hooks (0.2.0). `Navigator` gains three defaulted methods. R3 `name_matches(&self, node, name: &ExpandedName) -> bool` (default: `name(node) == Some(name)`, read errors are a non-match); `eval.rs` uses it for every `NodeTest::Name` test. R6 `children_named(&self, parent, name) -> Option<Vec<Node>>` (default `None`); `eval.rs` asks it for every `child::` step with a name test whose expanded name resolved, keeps only `NodeKind::Element` results, and otherwise scans `children()` with `name_matches`. R2 `child_by_key(&self, parent, name, keys: &[(ExpandedName, Value<Node>)]) -> Option<Option<Node>>` (default `None`); `eval.rs` (`key_run`, `child_by_key`, `key_child`, `context_independent`) recognizes the leading run of predicates `Binary(Eq, Path{child::k, no predicates}, rhs)` in either order with `rhs` a `String`, `Number`, `Variable`, `current()` call or `Path` whose base is a `current()` call; any other predicate ends the run. Each `rhs` is evaluated once at the step's context node (position 1 of 1) and passed verbatim. `Some(Some(n))` → `[n]` then the remaining predicates; `Some(None)` → empty; `None`, or a failed `rhs` evaluation, → ordinary evaluation with the work budget restored. R5 (`context.rs`): `FunctionTable<N>` (`new`, `insert(ExpandedName, Fn + 'static) -> &mut Self`, `Default`); `Context::with_functions(&'a FunctionTable<N>)`; lookup order core functions, then `with_function` closures, then the table. `Context::set_node(&mut self, node)` sets node, position 1, size 1 and nothing else.

Shared namespaces (0.3.0, WP9). `namespaces.rs` owns `Namespaces` (`pub mod namespaces`, re-exported at the root): `new()`, `with_namespace(prefix, uri)`, `with_default_element_namespace(uri)`, `namespace(&self, prefix) -> Option<&str>`, `default_element_namespace(&self) -> &str`, `Default`; private `map: BTreeMap<String,String>`, `default_element_namespace: String`, and two caches `resolved: RefCell<HashMap<QName, Rc<ExpandedName>>>` (names resolved with an unprefixed name in the null namespace: variables, functions, attributes, prefixed element tests) and `resolved_elements: RefCell<HashMap<String, Rc<ExpandedName>>>` (unprefixed element tests in the default element namespace, keyed by local name). `Context` gains `shared_namespaces: Option<&'a Namespaces>` and `with_namespaces(&'a Namespaces)`. In `eval.rs`, `namespace(prefix) -> Result<&str>` resolves `xml` first, then the context's own map, then the shared set; `name(&QName) -> Result<Rc<ExpandedName>>` and `element_name(local) -> Rc<ExpandedName>` (default element namespace: the context's own if non-empty, else the shared one) read and write the shared caches only when the context's own map and own default element namespace are both empty. `namespace` returns `&'a str` borrowed for the evaluator's context lifetime; `ResolvedTest<'t>` holds `Name(Rc<ExpandedName>)`, `Namespace(&'t str)` and `Pi(Option<&'t str>)`; `matches`, `children_named`, `key_run`/`child_by_key` use `&*rc`, and `Navigator::child_by_key` still receives owned `ExpandedName` keys. `ast::QName` derives `Hash`.

Node-set pool (0.3.0, WP9). `pool.rs` (private module, `NodeSetPool` re-exported at the root) owns `NodeSetPool<T> { buffers: RefCell<Vec<Vec<T>>> }`: `new()`, `take(&self) -> Vec<T>` (a pooled buffer or `Vec::new()`, always empty), `give(&self, Vec<T>)` (clears, keeps capacity; drops zero-capacity vectors and any vector once 64 are held), `len`, `is_empty`, `Default`, `Debug`. `Context` gains `pool: Option<&'a NodeSetPool<N::Node>>` and `with_pool(&'a NodeSetPool<N::Node>)`. In `eval.rs`, `Evaluator::take()`/`give(buffer)`/`give_value(value)` fall back to `Vec::new()`/drop without a pool. Discipline: every intermediate node-set buffer (`step`'s input, per-node `matching`, `filter` output after appending, `axis`/`children`/`push_children`/`descendants`/`siblings` results, the `child_by_key` result and its key values, `children_named` hook vectors, predicate values, discarded operands of `binary`/`scalar_binary`, unary operands, function arguments, union inputs) is taken from and given back to the pool; `normalize` sorts and deduplicates in the buffer it was given; a variable's node-set is copied into a pooled buffer. The value an evaluation returns is never given back by the evaluator. Results are identical with and without a pool. `key_run(step, test) -> Option<(Rc<ExpandedName>, usize)>` returns the step name and the run length (no vector; a key whose prefix is unbound ends the run), and `child_by_key(node, name, keys: &[Expr], depth)` re-reads each pair with the free function `key_pair(&Expr) -> Option<(&QName, &Expr)>` and resolves its name through `test_name` (cached when warm).
